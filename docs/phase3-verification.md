## 保存後の応答切断

ローカルの検証用中継サーバーで、Googleが保存成功を応答した後に、ブラウザへ返す接続だけを1回切断した。Googleの権限・設定・保存処理は変更していない。

1. 画面が保存成功を表示せず、「保存結果を確認できません」と案内した。
2. 入力内容を保持し、結果不明の間は修正画面へ進まないことを確認した。
3. 「同じ内容で保存結果を再確認」を押すと、同じリクエストIDで再送され成功した。
4. 画面の保存IDとシートの保存IDが一致し、対応する行が1件だけであることを確認した。

これはGoogle保存後の応答喪失に対する実保存を伴う試験であり、Google内部の障害を起こした試験ではない。
